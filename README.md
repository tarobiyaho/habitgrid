# 🔥 HabitGrid

Habit tracker with GitHub-style heatmap calendar and streak tracking.

## Features

- Create habits with custom emoji and color
- One-click daily check-in
- 365-day heatmap visualization (like GitHub contributions)
- Streak tracking (current + best)
- Total check-in statistics
- Dark theme UI

## Quick Start

```bash
pip install -r requirements.txt
python main.py
# → http://localhost:8013
```

## Stack

Python 3.10+, FastAPI, SQLite, vanilla HTML/CSS/JS
